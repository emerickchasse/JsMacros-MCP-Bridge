# Changelog

All notable changes to JsMacros MCP Bridge are documented here.

## 2.0.3-mcp.1

- Added the `execute_mc_jsmacros` MCP tool.
- Added the official MCP Java SDK 2.0 Streamable HTTP transport.
- Added an embedded local HTTP server at `http://127.0.0.1:25580/mcp`.
- Added Cloth Config and Mod Menu integration.
- Added configurable bind address, port, endpoint, timeout, enabled state, and optional API key.
- Added English and French MCP configuration translations.
- Added clean MCP startup and shutdown with the Minecraft client lifecycle.
